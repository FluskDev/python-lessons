## 📖 Урок 3. Мок-существо для тестов

### 🎯 Цель
Создать `MockCreature` — заглушку с тем же интерфейсом, что у Андрея. Это твой «заместитель» существа, пока он не закончил.

### 📝 Создай `timur/mock_creature.py`

```python
"""Заглушка существа для разработки мира.

Имеет ТОЧНО ТАКОЙ ЖЕ интерфейс, как andrey.creature.Creature.
Когда Андрей закончит, заменим импорт в world.py.
"""


class MockCreature:
    """Упрощённое существо для тестов мира."""

    def __init__(self, x, y, genes):
        self.x = x
        self.y = y
        self.genes = genes
        self.energy = 100.0
        self.age = 0
        self._alive = True

    @property
    def is_alive(self):
        return self._alive

    def tick(self):
        self.age += 1
        # Простая потеря: size=1 -> 1 энергии, size=2 -> 2, и т.д.
        self.energy -= 1.0 * self.genes.get("size", 1.0)
        if self.energy <= 0:
            self._alive = False

    def eat(self, food_value):
        self.energy = min(200.0, self.energy + food_value * 30)

    def can_reproduce(self):
        return self.energy >= 80.0 and self._alive

    def reproduce_with(self, partner):
        # Просто копирует гены партнёра (без мутаций — это мок)
        child = MockCreature(self.x, self.y, dict(partner.genes))
        self.energy -= 40
        partner.energy -= 40
        return child
```

### 🔍 Разбор

- **Имена и поведение методов** — должны ТОЧНО совпадать с тем, что делает Андрей (см. контракт).
- **`@property is_alive`** — у тебя и Андрея одинаково. Это важно, иначе потом замена сломается.
- **Возвращаемое `reproduce_with`** — новое существо. У Андрея так же.
