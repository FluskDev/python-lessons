## 📖 Урок 2. Класс World с пустым полем

### 🎯 Цель
Класс `World` — пустое поле `width × height` с возможностью добавлять еду.

### 📝 Создай `timur/world.py`

```python
"""Мир симуляции: поле, еда, существа."""


class World:
    """Прямоугольное поле, на котором живут существа и лежит еда."""

    def __init__(self, width: int, height: int):
        self.width = width
        self.height = height

        # Словарь еды: {(x, y): количество еды}
        # Если клетка не в словаре — еды нет.
        self.food = {}

        # Список существ на поле
        self.creatures = []

    def in_bounds(self, x: int, y: int) -> bool:
        """Находится ли клетка внутри поля?"""
        return 0 <= x < self.width and 0 <= y < self.height

    def add_food(self, x: int, y: int, value: float = 1.0) -> None:
        """Положить еду на клетку. Если там уже была — прибавить."""
        if not self.in_bounds(x, y):
            return
        self.food[(x, y)] = self.food.get((x, y), 0.0) + value

    def add_creature(self, creature) -> None:
        """Положить существо на поле (если клетка внутри поля)."""
        if self.in_bounds(creature.x, creature.y):
            self.creatures.append(creature)

    @property
    def alive_creatures(self):
        """Только живые существа (для удобства)."""
        return [c for c in self.creatures if c.is_alive]
```

### 🔍 Разбор

- **`self.food`** — словарь с ключом-кортежем `(x, y)`. Удобно: `world.food.get((3, 5), 0)` — сколько еды на клетке (3, 5).
- **`self.creatures`** — список. Может включать мёртвых, отфильтруем через `alive_creatures`.
- **`in_bounds`** — единая проверка «не выходит ли за границу». Чтобы не дублировать.
- **`@property`** — `world.alive_creatures` без скобок.
