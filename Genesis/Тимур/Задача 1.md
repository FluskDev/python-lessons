# Задача 1. Первое окно pygame

---

## 1. Установка (один раз)

Перед началом установи две библиотеки — pygame для графики и pytest для будущих тестов:

```bash
pip install pygame pytest
```

Проверь, что всё установилось:

```bash
python -c "import pygame; print('pygame', pygame.version.ver)"
python -m pytest --version
```

Если pygame не ставится — скажи преподавателю. На Windows иногда нужны дополнительные шаги.

---

## 2. Цель

Убедиться, что pygame работает, и увидеть на экране первое окно с текстом. После запуска должно открыться тёмное окно 800×600, в левом верхнем углу — надпись, окно закрывается по крестику.

---

## 3. Создание файла `timur/main.py`

Создай файл `timur/main.py` и вставь в него следующий код:

```python
"""Точка входа: запускает симуляцию."""
import pygame


def main():
    # 1. Инициализация pygame
    pygame.init()

    # 2. Создаём окно 800x600 пикселей
    screen = pygame.display.set_mode((800, 600))
    pygame.display.set_caption("Genesis — урок 1")

    # 3. Словарь цветов в формате RGB
    COLORS = {
        "bg":      (15, 15, 25),     # почти чёрный с синевой
        "text":    (220, 220, 255),  # почти белый
    }

    # 4. Шрифт для текста
    font = pygame.font.SysFont("Arial", 24)

    # 5. Главный цикл
    running = True
    clock = pygame.time.Clock()  # для контроля FPS

    while running:
        # Обработка событий (закрытие окна и т.п.)
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False

        # Рисуем
        screen.fill(COLORS["bg"])
        text = font.render("Урок 1: окно работает! Закрой меня.", True, COLORS["text"])
        screen.blit(text, (20, 20))

        # Показываем кадр
        pygame.display.flip()

        # 30 кадров в секунду
        clock.tick(30)

    pygame.quit()


if __name__ == "__main__":
    main()
```

---

## 4. Разбор кода

- **`pygame.init()`** — обязательно в начале. Без этого не будут работать рисование, звук, ввод.
- **`pygame.display.set_mode((800, 600))`** — создаёт окно. Размер в пикселях.
- **`screen.fill(color)`** — закрашивает весь экран одним цветом. Иначе будет «грязь» от предыдущего кадра.
- **`pygame.event.get()`** — возвращает список событий с прошлого кадра (клики, нажатия, закрытие).
- **`pygame.display.flip()`** — показывает то, что мы нарисовали. Без этого экран не обновится.
- **`clock.tick(30)`** — задержка, чтобы было 30 кадров/сек. Без этого программа жрёт 100% CPU.

---

## 5. Ожидаемый результат

### 5.1. Что должно появиться на экране

Запусти программу командой:

```bash
python timur/main.py
```

Через секунду должно открыться окно:

- **Размер:** 800×600 пикселей
- **Заголовок окна:** `Genesis — урок 1`
- **Фон:** тёмный (почти чёрный с синевой)
- **В левом верхнем углу:** белый текст `Урок 1: окно работает! Закрой меня.`
- **Закрытие:** нажал на крестик — окно закрылось, программа завершилась, в консоли снова появился ввод команд

### 5.2. Проверка, что окно действительно «живёт»

Открой окно и подвигай мышью над ним, пощёлкай по области окна — ничего не должно зависнуть и не должно появиться никаких ошибок в консоли.

## 6. Типичные ошибки

| Что видишь | Что случилось | Как чинить |
|---|---|---|
| `ModuleNotFoundError: No module named 'pygame'` | pygame не установлен | Выполни `pip install pygame`. Если ошибка про `--no-cache-dir` или «permission denied» — открой терминал от администратора или используй `pip install --user pygame` |
| `ModuleNotFoundError: No module named 'pytest'` | pytest не установлен (для будущих уроков) | `pip install pytest` |
| Окно открывается и сразу закрывается | Не хватает `while running:` — программа выходит до первого кадра | Проверь, что весь код от `running = True` до `pygame.quit()` идёт подряд, без лишних отступов |
| Окно открылось, но текста нет (чёрный экран) | Не отработал `font.render` или `screen.blit` | Проверь, что строка с `text = font.render(...)` идёт **до** `pygame.display.flip()`. Проверь, что шрифт `Arial` есть в системе (на Windows — есть) |
| Окно не закрывается по крестику | Нет обработки `pygame.QUIT` | Проверь, что в цикле `for event in pygame.event.get():` есть ветка `if event.type == pygame.QUIT:` |
| Окно «моргает» / мерцает | Нет `clock.tick(30)` или `pygame.display.flip()` | Проверь, что обе строки есть в конце тела цикла `while` |
| Ошибка `pygame.error: video system not initialized` | Забыл `pygame.init()` в самом начале `main()` | Добавь `pygame.init()` первой строкой после `def main():` |
| Ошибка `IndentationError: expected an indented block` | Где-то потерян отступ (пробелы или Tab) | Проверь, что строки внутри `def main():` и внутри `while running:` сдвинуты на 4 пробела. Не смешивай Tab и пробелы |
| Окно открылось, но висит после закрытия, не возвращает ввод | Не хватает `pygame.quit()` в конце | Добавь `pygame.quit()` после цикла `while` |
