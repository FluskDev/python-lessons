### Шаг 4. Создай `timur/test_creature.py`

Миру (уроки 4–6) от существа нужно вот это:

```text
creature.x                 — координата
creature.y                 — координата
creature.genes             — словарь генов
creature.energy            — запас энергии
creature.age               — возраст
creature.is_alive          — живое ли (это свойство, а не метод)
creature.tick()            — один шаг: стареет и тратит энергию
creature.eat(value)        — покормить
creature.can_reproduce()   — может ли размножаться
creature.reproduce_with(other) — родить потомка
```

Напиши тест на каждый пункт — так и проверишь, что у Андрея всё готово:

```python
"""Проверяем, что существо Андрея умеет всё, что нужно миру."""
from andrey.creature import Creature


def test_position():
    """У существа есть координаты."""
    c = Creature(x=3, y=4, genes={})
    assert c.x == 3
    assert c.y == 4


def test_genes():
    """У существа есть гены."""
    c = Creature(x=0, y=0, genes={"speed": 1.5, "size": 2.0})
    assert c.genes["size"] == 2.0


def test_energy_and_age():
    """Новое существо живое, у него 100 энергии и возраст 0."""
    c = Creature(x=0, y=0, genes={})
    assert c.is_alive is True
    assert c.energy == 100.0
    assert c.age == 0


def test_tick():
    """За тик существо стареет и тратит энергию по гену size."""
    c = Creature(x=0, y=0, genes={"size": 2.0})
    c.tick()
    assert c.age == 1
    assert c.energy == 98.0  # size = 2.0 -> минус 2.0


def test_eat():
    """Существо ест и восстанавливает энергию."""
    c = Creature(x=0, y=0, genes={})
    c.eat(1.0)
    assert c.energy == 130.0  # еда 1.0 -> плюс 30 энергии


def test_can_reproduce():
    """Сытое живое существо может размножаться."""
    c = Creature(x=0, y=0, genes={})
    c.energy = 200.0
    assert c.can_reproduce() is True
    c._alive = False
    assert c.can_reproduce() is False


def test_reproduce_with():
    """Существо может родить потомка."""
    a = Creature(x=1, y=1, genes={"size": 1.0})
    b = Creature(x=2, y=1, genes={"size": 1.0})
    child = a.reproduce_with(b)
    assert isinstance(child, Creature)
    assert child.is_alive is True
```

### ⚠️ Если что-то пошло не так

| Что видишь | Что случилось | Как чинить |
|---|---|---|
| `ModuleNotFoundError: No module named 'andrey'` | Запустил pytest не из папки `Genesis` | Сделай `cd Genesis`, потом `python -m pytest timur/ -v` |
| `ImportError: cannot import name 'MockCreature'` | В тестах осталась старая строка `from timur.mock_creature import MockCreature` | Замени её на `from andrey.creature import Creature` |
| `AttributeError: 'Creature' object has no attribute 'eat'` | У Андрея метод называется `food()` | Это нормально, запиши в табличку из шага 5 |
| `AssertionError` в `test_tick` | В генах нет `size` | Проверь, что в тесте гены содержат `"size": 2.0` |
