## 1. Контракт с Тимуром

Тимур будет вызывать у твоих существ эти методы и читать эти свойства. Имена и поведение — фиксированные. Если хочешь что-то переименовать — скажи Андрею заранее, ДО того, как он начнёт это использовать.

```python
creature.x              # int  — позиция по горизонтали
creature.y              # int  — позиция по вертикали
creature.is_alive       # bool — живо ли ещё
creature.genes          # dict[str, float] — гены (Тимур только ЧИТАЕТ)
creature.energy         # float — текущая энергия
creature.age            # int — возраст в шагах
creature.tick()         # -> None — прожить один шаг
creature.eat(value)     # -> None, value: float — поесть
creature.can_reproduce()   # -> bool
creature.reproduce_with(other)  # -> Creature — сделать потомка
```

---

## 2. Цель

Создать класс `Creature` с базовыми свойствами: позиция, гены, энергия, возраст, флаг жизни.

---

## 3. Создание файла `andrey/creature.py`

Создай файл `andrey/creature.py` и вставь в него следующий код:

```python
"""Класс существа для симулятора эволюции Genesis."""


class Creature:
    """Одно существо на поле.

    Атрибуты:
        x, y:        позиция на поле (целые числа)
        genes:       словарь генов {имя: число}
        energy:      текущая энергия (0..200)
        age:         возраст в шагах симуляции
    """

    def __init__(self, x: int, y: int, genes: dict):
        # Позиция — куда поставили существо на поле
        self.x = x
        self.y = y

        # Гены — характеристики существа (словарь)
        self.genes = genes

        # Стартовая энергия
        self.energy = 100.0

        # Возраст — пока 0, будет расти каждый шаг
        self.age = 0

        # Флаг жизни. Используем _alive (с подчёркиванием),
        # потому что is_alive — это property (см. ниже).
        self._alive = True

    @property
    def is_alive(self) -> bool:
        """True, если существо ещё живо."""
        return self._alive

    def __repr__(self) -> str:
        """Красивый вывод при print(). Удобно для отладки."""
        return (
            f"Creature(pos=({self.x},{self.y}), "
            f"energy={self.energy:.1f}, age={self.age})"
        )
```

---

## 4. Разбор кода

- **`x, y`** — координаты на сетке мира. Тимур будет их читать и иногда менять.
- **`genes`** — словарь с числами. Ключи фиксированные: `speed`, `size`, `vision`, `aggression`.
- **`energy`** — запас «жизни». Когда упадёт до 0, существо умрёт.
- **`age`** — счётчик шагов. Полезно для статистики.
- **`_alive`** — приватный флаг. Снаружи читаем через `is_alive`.
- **`@property`** — это «геттер». Снаружи пишут `c.is_alive`, а Python вызывает функцию.
- **`__repr__`** — магический метод. Срабатывает при `print(c)`. Полезно для отладки.

## 5. Создание тестов в `andrey/test_creature.py`

Создай файл `andrey/test_creature.py` со следующим кодом:

```python
"""Тесты для класса Creature. Запуск: python -m pytest andrey/ -v"""
from andrey.creature import Creature


def test_creature_starts_alive():
    """Новорождённое существо живо."""
    genes = {"speed": 1.5, "size": 2.0, "vision": 3.0, "aggression": 0.1}
    c = Creature(x=0, y=0, genes=genes)
    assert c.is_alive
    assert c.energy == 100.0
    assert c.age == 0


def test_creature_has_position():
    """Позиция сохраняется."""
    c = Creature(x=5, y=7, genes={})
    assert c.x == 5
    assert c.y == 7


def test_creature_has_genes():
    """Гены лежат в словаре, можно читать."""
    genes = {"speed": 2.0, "size": 1.5, "vision": 4.0, "aggression": 0.5}
    c = Creature(x=0, y=0, genes=genes)
    assert c.genes["speed"] == 2.0
    assert c.genes["aggression"] == 0.5
```

## 7. Типичные ошибки

Внизу под упавшим тестом pytest напишет, какая именно проверка не сработала. Вот шпаргалка по самым частым ошибкам этого урока:

| Что написано в ошибке | Что случилось | Как чинить |
|---|---|---|
| `AssertionError: assert 0 == 100.0` в `test_creature_starts_alive` | Забыл строку `self.energy = 100.0` в `__init__` | Добавь её после `self.age = 0` |
| `AssertionError: assert 0 == 5` в `test_creature_has_position` | Перепутал порядок: `self.y = x`, `self.x = y` | Поменяй местами |
| `KeyError: 'aggression'` в `test_creature_has_genes` | В тестовом `genes` нет такого ключа (опечатка) | Проверь написание: `aggression`, не `agresion` |
| `AttributeError: 'Creature' object has no attribute '_alive'` | Использовал `self.alive` вместо `self._alive` | Замени на `_alive` |
| `NameError: name 'Creature' is not defined` при запуске | Файл лежит не в `andrey/`, или опечатка в имени | Проверь, что `creature.py` лежит в `Genesis/andrey/`, имя класса с большой буквы |
| `ModuleNotFoundError: No module named 'andrey.creature'` | Запускаешь не из корня `Genesis/`, или нет `__init__.py` | Перейди в `Genesis/` и запусти снова. `__init__.py` создавать не нужно — папка и так будет работать как пакет, если в ней лежат `.py` файлы и ты запускаешь `pytest` из корня |
